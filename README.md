# Krzyżówka panoramiczna

Interaktywna krzyżówka o wykładach i nauczaniu w dużych grupach. Zestaw główny równomiernie obejmuje cztery działy: rolę wykładów, projektowanie angażujących wykładów, strategie interakcji oraz balans między wykładem a aktywnością.

## Bank pytań

Na stronie zestaw główny zawiera 400 pytań — po 100 z każdego działu. Dodatkowe pytania są dostępne przez przełącznik „Pokaż też pytania dodatkowe”. Łącznie bank zawiera 682 pozycje.

Pliki CSV i JSON z dodatkowymi pytaniami 601–682 znajdują się w katalogu `data/`. Są to autorskie definicje dydaktyczne, nie nowe wyniki badań.

## Publikacja na GitHub Pages

1. W ustawieniach repozytorium otwórz **Settings → Pages**.
2. Jako źródło wdrażania wybierz **GitHub Actions**.
3. Workflow wdroży stronę po każdym wypchnięciu zmian na gałąź `main`. Można go też uruchomić ręcznie w zakładce **Actions**.
